# Android 版 sing-box

SFA 允许用户管理和运行本地或远程的 sing-box 配置文件，并提供
平台特定的功能实现，例如 TUN 透明代理实现。

## :material-graph: 系统要求

* Android 5.0+

## :material-download: 下载

* [Play Store](https://play.google.com/store/apps/details?id=io.nekohasekai.sfa)
* [Play Store（Beta）](https://play.google.com/apps/testing/io.nekohasekai.sfa)
* [GitHub Releases](https://github.com/SagerNet/sing-box/releases)
* [F-Droid](https://f-droid.org/packages/io.nekohasekai.sfa/)（通过可重现构建统一签名）
