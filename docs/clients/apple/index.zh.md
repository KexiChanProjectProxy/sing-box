# Apple 平台版 sing-box

SFI/SFM/SFT 允许用户管理和运行本地或远程的 sing-box 配置文件，并提供
平台特定的功能实现，例如 TUN 透明代理实现。

    由于非技术原因，我们暂时无法更新 App Store 上的 sing-box 应用，也无法发布 macOS 独立客户端（TestFlight 用户不受影响）

## :material-graph: 系统要求

* iOS 15.0+ / macOS 13.0+ / Apple tvOS 17.0+
* 一个位于中国大陆境外的 Apple 账户
