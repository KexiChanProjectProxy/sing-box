### Connection Router Integration
All protocols use `adapter.ConnectionRouterEx` interface via two patterns:
1. Direct: `router.RouteConnectionEx()` / `RoutePacketConnectionEx()`
2. UOT wrapper: `uot.NewRouter()` for Universal UDP over TCP handling

No protocols use deprecated `RouteConnection()` / `RoutePacketConnection()` directly in runtime paths.

### Event-Based Logging Integration
All protocols consistently use the fork's event-based logging pattern:
- `log.NewConnectionEvent("inbound", "start/error")`
- `log.WithConnectionEvent(logger, ctx, level, event, message)`

This matches the established pattern from Task 11 and is consistent across all protocol inbounds.

### Sniffer Integration
- Sniff packages build and test successfully
- No stale sniffer assumptions found in inbound code
- Sniffing happens at route level (route/route.go) using adapter.InboundContext

### Auth Integration
- `common/auth/skip_auth.go` provides SourceInPrefixes for skip auth logic
- `auth.UserFromContext<T>()` pattern used for user extraction in VLESS, VMess, Trojan
- Authenticator pattern used in HTTP, TUIC, AnyTLS, Naive

## Conclusion
All inbound/protocol integration surfaces are properly aligned with:
1. Stabilized route/adapter contracts (ConnectionRouterEx)
