# Android 平台的 sing-box

SFA 允许用户管理并运行本地或远程的 sing-box 配置文件，并提供
平台特定的功能实现，例如 TUN 透明代理。

## :material-graph: 系统要求

* Android 5.0 及以上

## :material-download: 下载

* [Google Play](https://play.google.com/store/apps/details?id=io.nekohasekai.sfa)
* [Google Play (Beta)](https://play.google.com/apps/testing/io.nekohasekai.sfa)
* [GitHub Releases](https://github.com/SagerNet/sing-box/releases)
* [F-Droid](https://f-droid.org/packages/io.nekohasekai.sfa/)（通过可重现构建实现统一签名）
