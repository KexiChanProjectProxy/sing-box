## Runtime Surface Analysis

### 1. gRPC Contract Layer (daemon package)

The libbox package uses gRPC to communicate with the sing-box daemon service.
All protobuf messages in `daemon/started_service.pb.go` are aligned:

- **Status**: Memory, Goroutines, ConnectionsIn, ConnectionsOut, TrafficAvailable, Uplink, Downlink, UplinkTotal, DownlinkTotal
- **Connection**: Full metadata including ProcessInfo with AndroidPackageNames ([]string)
- **Groups**: Tag, Type, Selectable, Selected, IsExpand, Items with UrlTestTime/UrlTestDelay
- **ProcessInfo**: ProcessId (uint32), UserId, UserName, ProcessPath, PackageNames ([]string)

### 3. OutboundGroup Contract (adapter.OutboundGroup)

The daemon/started_service.go properly implements the OutboundGroup contract:

```go
type OutboundGroup interface {
    Outbound
    Now() string   // Currently selected outbound tag
    All() []string  // All available outbound tags
}
```

Usage in `readGroups()`:
- `iGroup.Tag()` → g.Tag
- `iGroup.Type()` → g.Type
- `iGroup.Now()` → g.Selected
- `iGroup.All()` → iterated for items
- `*group.Selector` type assertion for Selectable flag

### 4. URLTestHistoryStorage Contract

The daemon uses `urltest.HistoryStorage` correctly:

```go
type URLTestHistoryStorage interface {
    LoadURLTestHistory(tag string) *URLTestHistory
    DeleteURLTestHistory(tag string)
    StoreURLTestHistory(tag string, history *URLTestHistory)
}
```

Usage in `readGroups()`:
- `historyStorage.LoadURLTestHistory(adapter.OutboundTag(itemOutbound))` → item.UrlTestTime, item.UrlTestDelay
