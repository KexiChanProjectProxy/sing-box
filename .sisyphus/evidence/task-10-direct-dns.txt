## DNS Test Fix Applied

**Issue**: `dns/client_test.go` MockTransport did not implement the `Reset()` method required by `adapter.DNSTransport` interface after Task 8 core stabilization.

**Root Cause**: The merged `adapter.DNSTransport` interface (line 83-92 in `adapter/dns.go`) now includes:
```go
type DNSTransport interface {
    Lifecycle
    Type() string
    Tag() string
    Dependencies() []string
    Reset()  // <-- Added in upstream v1.13.11
    Exchange(ctx context.Context, message *dns.Msg) (*dns.Msg, error)
}
```

**Fix**: Added `Reset()` method to `MockTransport` in `dns/client_test.go`:
```go
func (t *MockTransport) Reset() {
}
```
